Вкладка «Кнопки» — руководство

Настройка и проверка Android-интентов для кнопок рации прямо в приложении — без физического устройства и без ручного ввода ADB-команд.

Панель устройств

Верхняя часть левого столбца. Показывает все ADB-устройства, видимые в данный момент: подключённые по USB и по WiFi (после применения WiFi на вкладке WiFi).

Выберите одно или несколько устройств чекбоксом — именно на них будут отправляться интенты при нажатии кнопок в правой панели. Кнопка Обновить переподключает WiFi-сессии и обновляет список.

Выбор нескольких устройств Кнопка «все / снять все» (иконка в заголовке «Устройства») позволяет выбрать или снять все авторизованные устройства за один клик — удобно при работе с парком одинаковых рации.

Список рации

Нижняя часть левого столбца, секция Рации. Содержит встроенные пресеты моделей рации и добавленные вручную устройства.

Кликните по модели — в правой панели откроется набор её кнопок. Повторный клик снимает выбор.

Кастомные рации Рации, добавленные вручную, помечены бейджем Кастом. При наведении курсора на строку появляется иконка редактирования (карандаш).

Кнопка-шестерёнка Кнопка ⚙ в заголовке секции «Рации» открывает экран управления файлами конфигурации — для экспорта, импорта и восстановления эталонного пресета.

Панель кнопок

Правая панель появляется после выбора рации. Содержит две секции: Кнопки (физические виджеты) и Интенты (таблица).

Выберите ADB-устройство Пока ни одно устройство не отмечено в левой панели, все кнопки и кнопки отправки в таблице интентов задизаблены — команды не будут отправляться.

Типы кнопок

ТипПоведение
Hold Нажатие вниз → press-интент;
удержание → longpress-интент;
отпускание → release-интент
Press Клик → press-интент; долгий клик → longpress-интент
Longpress Только долгий клик → longpress-интент
Knob Кнопка «‹» → ccw-интент (поворот влево);
кнопка «›» → cw-интент (поворот вправо)
Knob-виджет Knob отображается как горизонтальный контейнер с двумя круглыми кнопками и иконкой регулятора в центре. Подсказка с именем регулятора появляется при наведении курсора.

Таблица интентов

Ниже секции «Кнопки» — таблица со всеми интентами выбранной рации. Для каждой кнопки и события (press / release / longpress / cw / ccw) показывается полная строка action.

Кнопка справа от строки отправляет этот конкретный интент напрямую — без нажатия физической кнопки. Удобно для диагностики: можно проверить отдельный интент без физического устройства рации.

Быстрая диагностика Кнопки отправки в таблице позволяют проверить конкретный интент без подключённой физической рации — достаточно выбрать ADB-устройство и нажать кнопку отправки в таблице.

При нажатии отображается SnackBar «Отправляю: …». После получения ответа от устройства показывается результат (OK или сообщение об ошибке) на 6 секунд.

Добавление рации

Нажмите Добавить рацию в списке слева или в правой панели, чтобы открыть форму создания.

Поля формы

ПолеОписание
Название Отображаемое имя рации в списке (например, «TE590P Кастом»)
ID (slug) Уникальный идентификатор (только a-z, 0-9, _). Заполняется автоматически из названия, но можно изменить вручную

Кнопки внутри рации

Каждая кнопка настраивается отдельно:

  • Метка кнопки — отображаемое название (напр. PTT, SOS)
  • Тип — сегмент Hold / Press / Long / Knob
  • Поля событий — зависят от типа: Press action, Release action, Long press action, CW action (вправо), CCW action (влево)

Кнопки в списке можно перетаскивать (drag-handle слева от метки). Нажмите Добавить кнопку для добавления. Кнопка − удаляет (появляется только если кнопок больше одной; подтверждается диалогом «Удалить кнопку?»).

Редактирование встроенного пресета При редактировании встроенной рации (не-кастомной) появляется баннер: «Фабричный пресет. Изменения сохранятся в рабочий конфиг. Чтобы создать копию — измените ID.» Это позволяет скорректировать интенты встроенной модели без удаления оригинала.
Удаление кастомной рации Кнопка Удалить внизу формы доступна только для кастомных рации. После подтверждения в диалоге «Удалить устройство?» рация удаляется из конфига без возможности отмены.

Управление файлами конфигурации

Кнопка ⚙ в заголовке секции «Рации» открывает экран Настройка файлов конфигурации интентов. Конфигурация хранится в трёх независимых слоях, которые читаются в порядке приоритета: кастомные устройства → активный конфиг → эталон.

Как это работает в целом

При запуске приложение читает активный конфиг (devices_work.json). Если файл ещё не создан — он автоматически копируется из эталона, встроенного в ассеты приложения. Поверх активного конфига всегда накладываются кастомные устройства из custom_devices.json — они добавляются в список рации дополнительно к встроенным.

Активный конфиг

Рабочий конфиг, который используется в данный момент. Хранится в devices_work.json. Его можно редактировать прямо в приложении (добавлять и изменять рации через форму) или полностью подменить, импортировав свой JSON-файл. Подпись показывает источник:

  • Совпадает с эталоном — не изменялся — файл совпадает с эталоном (начальное состояние)
  • Источник: изменён пользователем — была добавлена или отредактирована рация через форму
  • Источник: импортирован из файла — файл загружен через кнопку «Импортировать»
КнопкаДействие
ЭкспортироватьСохранить активный конфиг в файл active_buttons.json
ИмпортироватьЗаменить активный конфиг из выбранного JSON-файла
Восстановить из эталонаПерезаписать devices_work.json из текущего эталона. Кастомные устройства при этом не затрагиваются

Кастомные устройства

Рации, добавленные через форму, хранятся отдельно в custom_devices.json и не теряются при «Восстановить из эталона». При импорте новые рации дополняют существующие — старые не удаляются.

КнопкаДействие
Экспортировать кастомныеСохранить кастомные рации в custom_devices.json
Импортировать кастомныеДобавить рации из JSON-файла поверх существующих (не заменяет, а дополняет)

Эталон

Базовый набор рации, из которого создаётся активный конфиг при первом запуске и который используется кнопкой «Восстановить из эталона». Существует в двух вариантах:

  • Поставляется с приложением (изменить нельзя) — встроенный файл внутри бандла приложения. Файл devices_reference.json в папке данных при этом отсутствует. Чтобы заменить — нажмите «Импортировать».
  • Пользовательский файл — в папке данных появился файл devices_reference.json, который был загружен через «Импортировать». Именно он теперь читается как эталон вместо встроенного. Кнопка «Сбросить к встроенному» удаляет этот файл и возвращает встроенный эталон.
КнопкаУсловиеДействие
ЭкспортироватьВсегдаСохранить текущий эталон в factory_buttons.json
ИмпортироватьВсегдаСкопировать выбранный JSON как devices_reference.json — он станет новым эталоном
Сбросить к встроенномуТолько если эталон — пользовательскийУдалить devices_reference.json и вернуть встроенный эталон из бандла
