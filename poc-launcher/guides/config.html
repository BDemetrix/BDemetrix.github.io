Вкладка «Конфиг» — руководство

Настройка параметров мобильного приложения ru.amettel.poc и запись конфигурации на подключённые устройства через ADB — без ручного редактирования JSON.

Конфигурация по умолчанию

При первом открытии вкладки активен встроенный профиль «По умолчанию». Он содержит стандартные параметры приложения и доступен только для чтения.

Изменить конфиг Встроенный профиль нельзя редактировать напрямую. Чтобы изменить настройки, создайте собственный профиль — так вы сможете хранить несколько вариантов конфигурации и быстро переключаться между ними.

Профили настроек

Профиль — это именованный набор параметров конфигурации. Все пользовательские профили сохраняются на диске и остаются доступны при следующем запуске лаунчера.

Где хранятся профили

ПлатформаПуть
macOS ~/Library/Application Support/ru.amettel.pocLauncher/poc-launcher/config/profiles/
Windows %APPDATA%\ru.amettel.pocLauncher\poc-launcher\config\profiles\
Linux ~/.local/share/ru.amettel.pocLauncher/poc-launcher/config/profiles/

Каждый профиль — отдельный .json-файл. Файлы можно копировать между компьютерами.

Создать профиль

  1. Нажмите Создать рядом со списком профилей.
  2. Введите название и нажмите Создать.

Новый профиль создаётся с теми же значениями, что и встроенный «По умолчанию». Удобно создать несколько профилей сразу — например, «Основной», «Склад А», «Выставка».

Дублировать профиль

Кнопка ⋮ → Дублировать создаёт копию текущего профиля — удобно, когда нужен вариант с небольшими отличиями, чтобы не настраивать всё заново.

Переключиться между профилями

Выберите нужный профиль в выпадающем списке вверху формы. При наличии несохранённых изменений лаунчер предложит подтвердить переключение.

Переименовать и удалить

⋮ → Переименовать и ⋮ → Удалить доступны только для пользовательских профилей. Удаление требует подтверждения.

Экспорт и импорт

  • ⋮ → Экспорт — сохранить конфигурацию в .json-файл.
  • ⋮ → Импорт — загрузить конфигурацию из .json-файла; создаётся новый профиль.

Редактирование параметров

Форма разбита на секции: Запуск, Звук, PTT, Группы и каналы и др. Нажмите заголовок секции, чтобы раскрыть её поля.

После редактирования нажмите Сохранить — изменения запишутся в профиль. Кнопка Отменить вернёт последнее сохранённое состояние.

Кастомные поля в стандартной секции

В любой раскрытой секции нажмите + Добавить поле и введите ключ, значение и описание. Поле помечается меткой custom.

Важно: кастомные поля могут быть проигнорированы Мобильное приложение применяет только те поля, которые ему известны. Кастомные поля, ключи которых приложение не распознаёт, будут проигнорированы при загрузке конфига на устройство. Добавляйте кастомные поля только если знаете, что приложение поддерживает соответствующий ключ.

Кастомные разделы

Нажмите + Добавить раздел в нижней части формы, введите название раздела и добавьте в него нужные поля. Такие разделы позволяют передать новые параметры в мобильное приложение, если оно их поддерживает, — без обновления лаунчера.

Кастомные разделы не гарантируют применения Мобильное приложение проигнорирует весь раздел целиком, если не знает о нём. Уточните поддерживаемые ключи у разработчиков приложения.

Применение конфигурации

Режим «Глобально»

По умолчанию активен режим «Глобально»: один профиль записывается на все отмеченные устройства одновременно. Отметьте нужные устройства чекбоксами и нажмите Применить профиль настроек.

Режим «По устройствам»

Если парк неоднородный — удобно назначить каждому устройству отдельный профиль. Переключитесь в режим «По устройствам»: у каждого устройства появится свой выпадающий список профилей.

JSON Preview

Панель JSON Preview в правой части экрана показывает итоговый JSON конфигурации в реальном времени — удобно убедиться, что именно будет записано на устройство, включая кастомные поля и разделы.
