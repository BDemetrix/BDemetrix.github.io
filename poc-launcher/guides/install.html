Вкладка «Установка» — руководство

Массовая установка APK и выдача разрешений для ru.amettel.poc на Android-устройствах через ADB.

Макет вкладки Слева — настройки (устройства, APK, учётные данные, кнопка запуска). Справа — панель прогресса установки с логом по каждому устройству.

Панель устройств

Верхний блок левой колонки показывает все Android-устройства, подключённые по USB и/или по WiFi (ADB over TCP). Кнопка Обновить вручную перечитывает список устройств через ADB и переподключает сохранённые TCP-устройства.

Автообновление Список обновляется автоматически — специально следить за появлением нового устройства не нужно.

Карточка устройства

Каждое устройство отображается карточкой с чекбоксом выбора. Щелчок по карточке переключает выделение (только для готовых устройств). Карточка содержит:

  • Название модели — например TE590P или TC2x.
  • Серийный номер в скобках — аппаратный S/N или ADB-идентификатор.
  • Производитель · Android версия, API — вторая строка под названием.
  • Бейджи подключения — USB и/или 192.168.x.x (WiFi-IP).

При нескольких устройствах в заголовке панели появляется кнопка «Выбрать все» — она выделяет или снимает выделение со всех доступных устройств.

Статусы устройств

ОтображениеЗначениеЧто делать
USB USB-устройство, ADB авторизовано. Готово к выбору и установке.
192.168.x.x Устройство доступно по ADB over WiFi. Можно отключить кабель — установка пройдёт по WiFi.
USB Требует авторизации
USB подключён, но разрешение USB-отладки не выдано. Чекбокс неактивен. Нажмите на оранжевый бейдж — появится диалог с пошаговой инструкцией.
USB Недоступно
USB-устройство только что отключилось. Карточка показывается ~3 сек, затем исчезает. Переподключите кабель.
192.168.x.x WiFi-устройство потеряло соединение — карточка немедленно исчезает из списка. Перейдите на вкладку WiFi → «Переподключить».

Авторизация USB-отладки

Почему появляется этот бейдж Бейдж Требует авторизации означает: USB-отладка на устройстве уже включена — устройство видно в ADB, но данный компьютер ещё не в доверенных. На экране устройства ожидает запрос «Разрешить отладку по USB с этого компьютера?». Если USB-отладка выключена — устройство не появится в списке вообще.
Выполняется на каждом устройстве отдельно Требует физического доступа — нужно взять устройство в руки и подтвердить запрос на его экране.

USB-отладка уже включена (типовой случай)

На экране устройства ждёт запрос — достаточно двух шагов:

  1. На экране устройства тапните «Разрешить» в запросе «Разрешить отладку по USB с этого компьютера?».
  2. Нажмите «Обновить список» в приложении — бейдж исчезнет.

USB-отладка не включена

Нажмите на бейдж — откроется диалог с полной инструкцией:

  1. Откройте Настройки → О телефоне.
  2. Нажмите «Номер сборки» 7 раз.
  3. Перейдите в Настройки → Параметры разработчика.
  4. Включите «Отладка по USB».
  5. Подтвердите запрос на устройстве.
  6. Нажмите «Обновить список» в приложении.

APK

Нажмите Выбрать APK — откроется системный диалог выбора файла (фильтр .apk). После выбора рядом появляется кнопка Убрать.

Кнопка … рядом с именем переключает между коротким именем файла и полным путём.

Путь сохраняется Выбранный APK запоминается между запусками. Если файл перемещён или удалён — появится предупреждение, кнопка «Установить» заблокируется.

Учётные данные

Переключатель Общие / По устройствам определяет режим ввода учётных данных.

Режим «Общие»

Один набор данных применяется ко всем выбранным устройствам.

ПолеОписание
ЛогинПоддерживает автодополнение из сохранённых значений.
ПарольКнопка 👁 показывает/скрывает. Пароль не логируется.
Адрес сервераФормат wss://hostname:port. Поддерживает автодополнение.
Сохранить учётные данныеСохраняются и подставляются при следующем открытии.

Режим «По устройствам»

Каждое устройство получает индивидуальные учётные данные — форма ввода переезжает в раскрываемую секцию карточки. Кнопка Заполнить (в правом углу заголовка блока «Учётные данные») копирует данные из общих полей во все карточки сразу.

Опции установки

ОпцияЭффект
Без очистки данных Пропускает pm clear ru.amettel.poc — настройки и кэш сохранятся.
Применить конфиг. настроек После установки отправляет OTAP-конфиг через broadcast ru.amettel.poc.ACTION_APPLY_OTAP_CONFIG.

Кнопка Сбросить шаги установки к дефолтным сбрасывает оба флага до значений из install.json.

Конфиг берётся в момент нажатия «Установить» Изменения на вкладке «Конфиг» после запуска не применятся к текущему заданию.

Профиль настроек

При включённом «Применить конфиг. настроек» и наличии пользовательских профилей появляется выпадающий список «Профиль настроек» — выбор, какой конфиг отправить на устройство после установки.

Встроенный профиль отображается как «По умолчанию». При единственном встроенном профиле список не показывается.

В режиме «По устройствам» каждому устройству можно назначить свой профиль — выпадающий список появляется в раскрытой карточке устройства.

▶ Запуск установки

Кнопка «Установить»

Кнопка активна только если выполнены все условия:

  • Выбрано хотя бы одно устройство.
  • Выбран APK-файл.
  • Установка в данный момент не запущена.

При нажатии кнопка переходит в ⏳ Установка… с анимацией. Установка на несколько устройств выполняется параллельно.

Сохранение учётных данных Если «Сохранить учётные данные» активно, данные сохраняются в момент нажатия кнопки.

Прогресс установки

Правая панель обновляется в реальном времени. Каждое устройство — отдельный раскрываемый блок. Нажмите на заголовок блока чтобы свернуть шаги.

Шаги сценария установки

«Условие пропуска» — при каком условии шаг не выполняется. Если условие не выполнено или прочерк — шаг всегда запускается.

Автоматическая выдача разрешений Все разрешения, которые возможно выдать программно, выдаются автоматически — не нужно заходить в настройки каждого устройства вручную.

Блок «Примечания»

Появляется после завершения. Содержит предупреждения (warn_only-шаги с ошибкой) и критические ошибки. Предупреждения группируются по типам.

Вкладка «Отчёт»

После завершения всех установок приложение автоматически переходит на вкладку «Отчёт» с итоговой сводкой: количество успешных/неудачных устройств, время. Каждое устройство — раскрываемая карточка с деталями по шагам.

Лог каждой установки автоматически сохраняется в TXT-файл. Кнопка Копировать копирует текст отчёта в буфер обмена. Кнопка Открыть папку логов открывает папку в файловом менеджере.

Расположение логов Основная папка — poc-launcher-logs внутри «Загрузок»:
macOS / Linux~/Downloads/poc-launcher-logs/
Windows%USERPROFILE%\Downloads\poc-launcher-logs\
Если папка загрузок недоступна — резервная папка:
macOS~/Library/Application Support/poc-launcher/logs/
Windows%APPDATA%\poc-launcher\logs\
Linux~/.local/share/poc-launcher/logs/
Имя файла: install_YYYY-MM-DD_HH-MM_Модель_Серийник.txt
