Проблемы которые решаем

Сейчас каждое устройство — это ручная работа

  • Установка — вручную на устройстве либо скриптом из терминала, запускается отдельно для каждого устройства вручную.
  • Разрешения — при установке из скачанного APK выдаются вручную: микрофон, геолокация, уведомления, фоновый режим — на каждом устройстве отдельно. Долго, рутина, утомляет, возможны ошибки.
  • WiFi на устройствах без экрана — подключение к сети невозможно без отдельных ADB-команд для каждого устройства в консоли.
  • Конфигурация — нет возможности загрузить пресет настроек сразу после установки и получить индивидуально сконфигурированное приложение без ручного изменения настроек или обращения к диспетчерскому приложению.
  • GPS-диагностика — без ручного ввода команд невозможно получить результат диагностики геолокации на устройстве.
  • Физические кнопки — проверить реакцию на нажатие кнопок на любом устройстве невозможно, не имея целевого устройства под рукой.
В итоге: 5–10 минут на одно устройство, большая вероятность ошибок — при ручной работе с терминалом легко пропустить шаг или опечататься. Делегировать задачу нельзя: без знания ADB-команд и специфики версий Android человек не сможет выполнить её корректно.

Возможности

Что умеет приложение

1

Установка и разрешения — автоматически

Выберите файл и нажмите «Установить» — Launcher сам выполнит все 15 шагов: установка, разрешения с учётом версии Android, оптимизация батареи, запуск сервиса.

  • Прогресс каждого шага в реальном времени
  • Разные учётные данные для каждого устройства
  • Параллельная работа с несколькими устройствами
  • Понятные объяснения ошибок на русском
2

Настройка WiFi без экрана

Введите название сети и пароль — Launcher настроит WiFi через кабель. После этого кабель можно убрать и работать по воздуху.

  • Android 8 и выше
  • Беспроводное сопряжение без USB — ввод кода с экрана устройства (Android 11+)
  • Подключения сохраняются между запусками
ADB — стандартный протокол Google для управления Android-устройствами с компьютера.
3

Редактор конфигурации

35+ параметров — автозапуск, PTT-кнопка¹, геолокация, звук — настраиваются через форму. Не нужно знать структуру JSON.

  • Профили: сохранить, загрузить, передать коллеге
  • Разные профили для разных серийных номеров
  • Применение одной кнопкой без переустановки
¹ PTT (Push-To-Talk) — кнопка на рации, переключающая режим передачи голоса.
4

Маппинг физических кнопок

Настройте и проверьте реакцию мобильного приложения на нажатие физических кнопок — без необходимости держать целевое устройство под рукой. Встроены пресеты для 11 моделей раций.

  • IRC590, M6, TE620, TE800, TE900 и другие — из коробки
  • Отправка команды и мгновенная проверка реакции приложения
  • Создание собственных маппингов
5

GPS-диагностика

Запустите проверку — Launcher выдаст понятный отчёт: геолокация включена, права выданы, сколько спутников, последний GPS-фикс.

  • Одновременная проверка нескольких устройств
  • Live-панель с координатами для полевой проверки
  • Отчёт копируется одной кнопкой
6

Отчёт и логи

После каждой установки — сводная таблица: что готово, что нет и почему. Лог сохраняется автоматически с датой и именем устройства.

  • Копирование отчёта одной кнопкой
  • Канал подключения (USB / WiFi) в отчёте
  • Быстрый переход к папке с логами
